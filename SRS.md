## 1. Введение

### 1.1. Цель документа

Настоящий документ определяет полный набор функциональных и нефункциональных требований к веб-платформе и Telegram-боту **Cinema Hikes** — онлайн-кинотеатру для бесплатного просмотра и скачивания фильмов без рекламы, разрабатываемому в рамках курсового командного проекта по дисциплине ASP.NET Core. Документ служит единым источником правды для команды разработки, QA и руководства на всех этапах жизненного цикла проекта: планирование, реализация, тестирование, документирование и защита.

### 1.2. Объем продукта

Cinema Hikes — это современная веб-платформа и Telegram-бот, предоставляющие пользователям возможность абсолютно бесплатно и без рекламы искать, просматривать онлайн и скачивать фильмы с нескольких источников. Проект реализуется как **командный проект** с применением системы контроля версий Git и архитектуры Clean Architecture, принципов программирования S.O.L.I.D.

## 2. Общее описание

### 2.1. Перспектива продукта

Cinema Hikes разрабатывается как самостоятельный онлайн-сервис стриминга и скачивания видеоконтента с нуля. Продукт решает ключевые проблемы существующих аналогов (таких как Kinogo, HdRezka): полное отсутствие всплывающей рекламы, баннеров и коммерческих видеовставок, а также современный, лаконичный и быстрый интерфейс. Система включает в себя клиентскую часть (React SPA), серверный API (ASP.NET Core), фоновые источники (Playwright), базы данных в Docker (PostgreSQL) и Telegram-бота (TelegramBot.Net).

### 2.2. Классы пользователей и привилегии

| Роль | Описание | Ключевые разрешения |
|---|---|---|
| Гость | Неавторизованный посетитель | Бесплатный онлайн-просмотр, поиск, фильтрация, перегляд деталей фильма |
| Авторизованный пользователь | Зарегистрированный пользователь веб-сайта | Избранное, история просмотров, персональные подборки |
| Пользователь Telegram-бота | Пользователь Telegram | Поиск фильмов, просмотр информации, бесплатное скачивание файлов через бота (в пределах лимитов Telegram) |
| Администратор | Менеджер платформы | CRUD фильмов, категорий, управление источниками, модерация отзывов, аналитика |
| Система | Автоматизированные процессы | Получение информации видеоплееров/источников (Playwright), кеширование, Telegram-уведомления |

## 3. Границы проекта

### 3.1. В рамках проекта (In Scope)

- Веб-сайт (React SPA) для просмотра фильмов онлайн с адаптивным плеером без рекламы
- Telegram-бот для поиска и бесплатного скачивания фильмов на устройство
- База данных PostgreSQL в Docker-контейнере для хранения каталога, пользователей, истории и метаданных
- Автоматическое получение видеоконтента из нескольких источников с использованием Playwright
- Поиск, фильтрация (по жанрам, годам, рейтингу) и пагинация
- Личный кабинет пользователя (избранное, история просмотра)
- Документация API (Swagger) и юнит-тесты (NUnit)

### 3.2. Вне рамок проекта (Out of Scope)

- Платные подписки и интегрированные рекламные модули (сервис 100% бесплатный)
- Нативные мобильные приложения (iOS/Android) — только адаптивный веб и Telegram-бот
- Собственное физическое хранилище всех петабайт видеофайлов (используются внешние CDN/источники)

## 4. Функциональные требования

*Формат: **[Приоритет MoSCoW]** ID — Описание → Критерий приемки (Acceptance Criteria)*

### 4.1. Каталог и Онлайн-просмотр (Веб-сайт)

**[Must] FR-01** — Просмотр каталога фильмов с пагинацией и фильтрацией (по жанрам, году выпуска, рейтингу).
→ *AC:* Время ответа API ≤ 300 мс при выборе фильтров; корректный вывод карточек фильмов с постерами и названием.

**[Must] FR-02** — Поиск фильмов по названию.
→ *AC:* Регистронезависимый поиск; вывод результатов в режиме реального времени или по нажатию Enter.

**[Must] FR-03** — Карточка фильма с подробной информацией (описание, год, жанры, актеры, рейтинг) и встроенным видеоплеером на странице фильма.
→ *AC:* Отсутствие рекламы при запуске и во время воспроизведения; возможность выбора качества и источника плеера.

**[Must] FR-04** — Выбор альтернативных источников плеера для одного и того же фильма.
→ *AC:* Если один источник недоступен, пользователь может в 1 клик переключиться на резервный плеер.

### 4.2. Telegram-бот (Скачивание и поиск)

**[Must] FR-05** — Поиск фильмов через Telegram-бота по названию.
→ *AC:* Бот возвращает список найденных фильмов с кнопками выбора.

**[Must] FR-06** — Бесплатное скачивание фильма прямо в Telegram или получение прямой ссылки на скачивание.
→ *AC:* При нажатии кнопки «Скачать» бот отправляет видеофайл в чат (если размер в пределах лимитов Telegram (2GB)).

### 4.3. Авторизация и Личный кабинет

**[Should] FR-08** — Регистрация и авторизация пользователей через login / пароль (JWT Bearer + Identity).
→ *AC:* Пароль минимум 6 символов

### 4.4. Фоновые процессы и Администрирование

**[Must] FR-10** — Фоновое получение плееров и потоков с помощью Playwright.
→ *AC:* Сервис автоматизирует получение актуальных ссылок на видеоконтент со сторонних ресурсов без передачи рекламных скриптов клиенту.

## 5. Use Cases

### UC-01: Бесплатный просмотр фильма на веб-сайте

| | |
|---|---|
| **Актер** | Гость / Авторизованный пользователь |
| **Предусловия** | Пользователь открыл веб-сайт Cinema Hikes |
| **Основной поток** | 1. Пользователь вводит название фильма в поиск или выбирает из каталога → 2. Переходит на страницу фильма → 3. Нажимает «Воспроизвести» → 4. Видеоплеер запускается сразу без рекламы |
| **Альтернативный поток** | 3a. Выбранный плеер не отвечает → Пользователь выбирает альтернативный источник из списка под плеером → Видео запускается |
| **Постусловия** | Видео успешно воспроизводится; запись добавляется в историю (если пользователь авторизован) |

### UC-02: Поиск и скачивание фильма через Telegram-бота

| | |
|---|---|
| **Актер** | Пользователь Telegram |
| **Предусловия** | Бот запущен (/start) |
| **Основной поток** | 1. Пользователь отправляет текстовое сообщение с названием фильма → 2. Бот выполняет запрос к API и возвращает inline-список совпадений → 3. Пользователь выбирает фильм → 4. Бот присылает карточку фильма с кнопкой «Скачать» → 5. Пользователь нажимает «Скачать» → 6. Бот отправляет видеофайл или прямую ссылку |
| **Постусловия** | Пользователь получает файл или ссылку для бесплатного скачивания |
